## 4. 交付三：推荐系统 v2（SDD）

规格：`docs/specs/推荐系统v2/01-需求规格.md`（问题清单、FR/NFR、AC-1~10）· `02-技术设计与任务拆解.md`（架构、决策表、任务、跟踪矩阵）。

**架构**：五路召回融合打分——CF 物品协同(0.50) / 内容特征 genre+language(0.25) / 歌手维度(0.15) / 全局热度(0.07) / 新鲜度(0.03)；"猜你喜欢"用另一组大盘权重。种子权重 = 收藏 2.0 + ln(1+播放) × 时间衰减（7 天 1.0 / 30 天 0.6 / 90 天 0.3）。硬过滤（已收藏/播放≥3 次/下架）→ 主歌手 40% 配额打散 → 每条结果带 `reason`（如"听过《素颜》的人也在听"）与 `strategy` 标识。用户级缓存 TTL 5 分钟，收藏/播放变更主动失效，`refresh=true` 从 3 倍候选池随机采样（换一批）。

**硬性成果**：推荐链路杜绝全表扫描（旧实现每次请求 `findAll()` 整表加载收藏+播放历史）；接口本地实测 ~180ms；冷启动用户自动落到热门+新歌。

**契约变更（破坏性，前后端同版本发布）**：`/music/recommend/personalized` 与 `/guess-you-like` 响应由 `List<Song>` 变为 `List<RecommendItemVO>`（`{song, score, reason, strategy}`）；`/similar-songs/{id}` 与 `/playlists` 契约不变。

**文件**：重写 `service/RecommendationService.java`；`RecommendationController.java`；新增 `dto/RecommendItemVO.java`；`FavoriteRepository`/`PlayHistoryRepository`/`SongRepository` 各增有界查询；`FavoriteService`/`PlayHistoryService` 挂缓存失效钩子；前端 `Discover.vue` 理由徽标（按策略着色）+ 换一批。

## 11. 2026-09-05 追加：管理后台封面排查 + SW 外域放行 + 导入链路验证

**现象**：管理后台改版后，用户浏览器（127.0.0.1:4173/#/admin）歌手头像显示字母、歌曲封面显示耳机占位。

**排查结论（证据链）**：
1. 数据层正常：直连库与 `/api/admin/song|artist/list` 均返回完整 cover/avatar URL（184 首歌 OSS 封面、40 位歌手外站头像）。
2. 渲染层无 bug：在受控 Chromium 中以相同 dist + 相同代理访问 #/admin，**10/10 封面与 10/11 头像全部解码成功**（img.naturalWidth > 0，el-image 无 error 槽；唯一字母头像对应 avatar 为 NULL 的测试数据，属正常降级）。
3. 唯一的页面级差异机制是 Service Worker：旧版 sw.js 对**所有**非导航 GET（含跨域图片）`respondWith`，SW 内 fetch 一旦失败会被兜底替换成 offline.html → 图片必然解码失败。而直接在浏览器地址栏打开图片 URL 不经过 SW，能正常显示——与"图片源没问题、页面里不显示"的现象吻合。
4. 修复：`public/sw.js` 新增**跨域请求直接放行**（`url.origin !== self.location.origin` 即 return，跨域响应本就进不了同源 Cache，拦截只有风险没有收益），缓存版本升至 `sheep-music-v4`（activate 自动清 v3 旧缓存）。
5. 用户浏览器若刷新后仍不显示：按 Ctrl+Shift+R 强刷让新 SW 接管；再不行检查系统代理/VPN（如"自由猫"）对 baidu/aliyuncs/y.qq.com 的拦截与浏览器扩展的图片过滤。

**导入中心验证（e2e 隔离库实例，PORT=19001）**：
- 现有实现已符合"直接上传音频 → OSS 返回 URL"：`el-upload → /api/upload/music` 返回 `data.url` 回填表单，再 POST `/admin/song/import`（后端 SongController/ArtistController 已有 `/import` 端点，DTO 与前端封装字段一一匹配）。
- 实测通过：歌手批量导入去重（3 名 → 2 建 1 跳过）；`song/import` 创建成功（已有歌手 + 按名自动建新歌手、字段落库、空参 400 校验）。
- **⚠ 阻塞项：本机环境变量里的 OSS AccessKey（LTAI5tFpjg…）已被阿里云判定不存在（InvalidAccessKeyId），当前所有上传必然 500。** 需到阿里云控制台更换有效的 `ALIYUN_OSS_ACCESS_KEY_ID/SECRET`。
- 顺带修复：ContentImport.vue 两个 el-upload 此前未绑 `:on-error`、成功回调忽略非 200——现在上传失败（含 HTTP 500 与业务 code≠200）都会弹出后端错误信息，不再静默。
