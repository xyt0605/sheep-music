# Sheep Music UI v3 · 整体视觉改造规格

> 日期：2026-08-31  
> 范围：仅调整前端呈现与交互层，不修改 API 契约、Pinia 状态结构和后端业务逻辑。

## 1. 改造目标

- 将登录页已经形成的「黑色影像、纸白信息、荧光青柠」视觉语言延伸到登录后的完整产品。
- 移除导航、页标题、标签页中的装饰性 emoji，统一使用 Element Plus 线性图标。
- 将登录后的界面定位为紧凑、可反复使用的个人音乐编辑台，而不是营销落地页。
- 统一首页、发现、榜单、歌单、歌手、我的音乐、社交和管理后台的页面标题、列表、卡片、表单、空状态与弹层。
- 保留明暗主题、桌面侧边栏、移动菜单、全局播放器和现有业务流程。

## 2. 视觉方向

- 主色：荧光青柠，用于播放、激活态和关键反馈。
- 中性色：墨黑、纸白和中性灰，承担主要表面层级。
- 辅助色：青色用于推荐信息，珊瑚色用于社交提醒与危险操作。
- 字体：正文使用窄体无衬线系统字体，中文展示标题使用宋体/衬线字体。
- 形状：卡片圆角不超过 8px；重复内容可使用卡片，页面区块保持无外框或仅用分隔线。
- 动效：只保留页面进入、悬浮播放、当前播放状态和抽屉过渡等有意义的反馈。

## 3. 功能与布局要求

- 桌面端使用固定深色侧边栏，顶栏提供历史导航、当前页面名称、快速搜索和用户工具。
- 首页首屏由紧凑问候栏、影像电台和推荐入口组成，并在常见桌面视口露出下一内容架。
- 音乐播放器固定贴底，使用清晰的三栏控制布局；移动端压缩为封面、歌曲信息和核心播放控制。
- 内容页统一页面头、筛选区、数据列表/卡片和操作按钮密度。
- 社交页保持高信息密度，聊天界面不使用装饰性大卡片。
- 390px、768px、1440px 视口下不得出现横向溢出、文字遮挡或不可点击操作。

## 4. 验收标准

1. 导航、页面标题和 Tab 不再依赖 emoji 传达含义。
2. 明暗主题下文字、边框、按钮和弹层对比度正常。
3. 首页、发现、我的音乐、聊天、个人中心和管理后台具有一致的表面与排版规则。
4. 播放器、队列、歌词、收藏、搜索和社交相关交互保持可用。
5. `npm run build` 通过，前端产物同步更新。
6. 使用桌面与移动视口截图检查首屏、溢出、遮挡和资源加载。
