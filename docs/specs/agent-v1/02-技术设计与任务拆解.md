# Agent v1 · 技术设计与任务拆解（SDD-Design & Tasks）

## 1. 总体架构

```
POST /agent/dj/stream（JWT，body {query}）
   └─ AgentController：SseEmitter(0L) + 专用线程池，调 Orchestrator
        AgentOrchestrator（手写状态机，Spring AI ChatClient）
        ① Dispatcher  call() → JSON 意图
        ② Librarian   ReAct 循环（≤4 动作）：模型输出 {thought,action,args}；
                      工具结果作为 observation 回填；候选以 ref 下标提名
        ③ DJ          stream() 串场词 → text_delta
        ④ Critic      call() 打分；不过 → 回②（≤2 轮）
        末端：song_card × N（含封面/歌词可播性由前端已有逻辑承接）→ done
```

工具实现 = 包装既有 Service（零业务改动）：
`search_local` → SongService 检索 · `recommend` → RecommendationService.personalized · `search_web` → ExternalMusicService("gequhai")

## 2. 关键设计决策

| # | 决策 | 理由 |
|---|------|------|
| D1 | 手写 ReAct 循环（JSON 动作协议），不用 Spring AI tool-calling | 过程事件可全程 SSE 播报；JSON 协议对推理模型（glm-4.5-air 会先思考）更稳；无框架黑盒 |
| D2 | 候选以 **ref 下标**提名，卡片字段全部由编排器回填 | 防幻觉：模型永远不生成 URL/ID；E2E 可断言字段与工具返回一致 |
| D3 | SseEmitter(0L) + 固定线程池（4），Orchestrator 在工作线程推事件 | MVC 原生 SSE，超时不设限（推理模型慢）；异常统一转 error 事件 |
| D4 | DJ 用 stream() 出串场词；卡片在 DJ 结束后统一发 | 流式观感 + 卡片字段由编排器构造，一次成型 |
| D5 | 提示词为 Java 常量（AgentPrompts），随 git 版本化 | "提示词即交付物"；P2 抽到 resources/prompts |
| D6 | 密钥经 `AGENT_API_KEY` 环境变量，`not-configured` 时 error 事件降级 | 密钥不入仓库；无 key 站点功能不受影响 |
| D7 | 模型 glm-4.5-air（用户资源包 12M tokens），`AGENT_MODEL` 可覆盖 | air 为推理模型：结构化 JSON 质量高；思考耗 token——各调用 max_tokens 1024~2048 |
| D8 | 本地优先合并去重（歌名+歌手），候选 ≤10 | 混排观感 + 控制卡片数 |
| D9 | 前端 fetch + ReadableStream 手解 SSE | EventSource 无法带 JWT 头 |
| D10 | 卡片渲染复用外源/本地双形态守卫（isExternal） | 曲库供应链已落地的防幻觉写操作约定直接生效 |

## 3. 后端新增（com.example.sheepmusic.agent）

| 文件 | 职责 |
|------|------|
| `AgentPrompts.java` | 四角色系统提示词常量（含 JSON 输出契约与反提示注入约束） |
| `DjTools.java` | 三个工具方法（返回带 ref 的条目列表 + 摘要文本给 LLM） |
| `AgentOrchestrator.java` | 四角色编排 + ReAct 循环 + SSE 推送 + 异常降级 |
| `AgentController.java` | POST /agent/dj/stream，SseEmitter，登录鉴权（默认规则） |

JSON 提取防御：剥 ```json 围栏 → 截取首个平衡 `{...}`；解析失败按该步重试一次，再失败降级（Librarian 解析失败=直接用工具结果；Critic 失败=视为通过）。

## 6. 风险与回退

| 风险 | 缓解 |
|------|------|
| 推理模型慢（整轮 15~60s） | 过程事件可视化；SSE 无超时；后续可换非推理 flash |
| LLM JSON 解析失败 | 防御性提取 + 重试一次 + 逐步降级（见 §3） |
| 歌曲海风控/改版影响 search_web | Librarian 工具异常转 observation，模型自适应；失败降级本地 |
| 密钥泄露（已出现在聊天记录） | 不入仓库；建议联测后到控制台轮换 |
| 多用户并发 LLM 调用 | 线程池上限 4 + 个人站定位；必要时加用户级限频 |
