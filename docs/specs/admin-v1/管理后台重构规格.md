# 管理后台重构规格

## 目标

将管理后台收敛为内容运营工作台，减少低频操作和重复录入，让歌手与歌曲导入在一个入口内完成。

## 页面结构

后台保留三个入口：

1. **导入中心**：批量导入歌手，或一站式导入歌曲。
2. **歌手管理**：搜索、编辑、删除歌手。
3. **歌曲管理**：按歌曲名/歌手名搜索，按上架状态筛选，编辑、删除歌曲。

原“批量编辑类型和语言”“快速设置类型”“快速设置语言”等低频弹窗移除；新增歌手和新增歌曲统一由导入中心承载。

## 导入流程

### 歌手

- 支持换行、中文逗号和英文逗号分隔。
- 前端先去重，后端再次按名称忽略大小写去重。
- 返回新增数量、已存在数量和解析后的歌手列表。

### 歌曲

- 必填项仅为歌曲名称、歌手和音频地址。
- 歌手分为“已有歌手”和“新歌手名称”两组输入。
- 新歌手在歌曲导入事务内自动创建，歌曲随后直接建立关联。
- 封面和音频既支持 OSS 上传，也支持粘贴 URL。
- 类型、语言、专辑、歌词、状态作为可选元数据一次提交。

## 接口

- `POST /admin/artist/import`
- `GET /admin/artist/list?keyword=...`
- `POST /admin/song/import`
- `GET /admin/song/list?keyword=...&status=...`

原有 CRUD 接口保留，用于兼容既有调用方。

## 验收标准

- 后台首屏可直接进入导入中心，不再出现新增、批量编辑等重复入口。
- 歌手导入重复名称不产生重复记录。
- 歌曲导入可同时关联已有歌手并创建新歌手。
- 歌曲列表支持关键词和状态组合筛选，分页由后端完成。
- 前端生产构建和后端 Java 8 编译通过。
