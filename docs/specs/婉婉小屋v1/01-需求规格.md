# 婉婉小屋 v1 · 需求规格（SDD-Spec）

> 「婉婉小屋」：为她（婉婉）专设的照片墙 + 视频墙板块。管理员在后台随时上传/管理素材（运行时生效，无需重新部署），并通过每日瞬间、音乐明信片、星星互动等轻元素传递陪伴感。
> 路由固定 `/memories`；素材默认全员可见（无 private 档，站内需登录）。

## 1. 背景与问题

1. 想为她建一个专属板块承载照片与视频回忆。现有 Moments（动态）是社交属性（可见范围/评论/公开点赞），不适合作为私密纪念载体；且新素材目前只能靠重新部署注入，运营成本高。
2. 她近期情绪波动大、有抑郁症状。这个板块不能只是"相册"——交互与文案需要按低压力、确定性的陪伴体验来设计（原则见 §3）。
3. 站点已有可复用资产：OSS 上传链路（FileUploadController/OSSUtil）、管理后台 tab 框架（Admin.vue）、本地曲库 + 播放器 store、SongSelector 选歌组件、小屋 DJ/小羊驼人格。

## 2. 目标（Goal）

1. 登录后可访问「婉婉小屋」页面：照片/视频瀑布流 + 按月时间轴分组 + 大图灯箱（配文/日期/背景音乐）。
2. 管理员在 /admin「记忆管理」tab 上传照片/视频（标题、配文、拍摄日期、绑定歌曲），发布/下架/编辑/删除全部**运行时生效**。
3. 内置治愈元素：每日瞬间（每天确定性推荐一张）、音乐明信片（照片绑定"那天的歌"）、星星互动（她的轻反馈，数据仅管理员可见）。
4. UI 风格：**粉嫩风**（她内心是一个小女孩）——粉色系渐变、圆角、柔和光晕、可爱贴纸元素；仅作用于小屋页，不污染站点 galaxy 主题。
5. 回归底线：既有功能不受影响；multipart 全局上限调整不破坏既有上传接口的自身校验。

## 3. 情感设计原则（Why——陪伴视角）

1. **确定性陪伴 > 热闹**：每日瞬间每天固定一张（当日不变），传递"有人持续在想着你"；页首展示"小屋里珍藏着 N 个瞬间"，是积累感而非任务感。
2. **零社交压力**：无评论、无他人点赞、无连续打卡、无未读红点。星星只有她自己能点，数据只给管理员看——他获得"她来过、她看过"的轻信号，但不做任何浏览记录式的 surveillance。
3. **慢与轻**：粉嫩暖色主题（区别于主站 galaxy 冷色调）、缓慢 Ken Burns/入场动画、尊重 prefers-reduced-motion；**绝不自动播放声音**，视频一律点击播放。
4. **音乐即记忆**：每张照片可绑定一首站内歌，灯箱一键播放"那天的 BGM"——用音乐站的核心能力做差异化，比纯图库更打动人。
5. **反馈是礼物不是负担**：点亮星星是她的主动行为，没有数量目标、没有比较对象；"你在这里点亮过 M 颗星"只对她自己可见。
6. **文案不说教**：避免"加油/想开点"式空洞正能量；用具体的小事和陪伴语气（配文由管理员亲手写，系统只提供温柔的容器）。
7. **粉嫩审美的边界**：可爱但不幼稚化她——粉色是氛围而非主题绑架，内容区保持简洁排版，避免满屏贴纸/flash 动画造成的视觉噪音。

## 4. 用户故事

1. 她（登录自己的账号）打开导航「婉婉小屋」：看到今天想给她看的瞬间（照片 + 他写的话），往下滑是按月分组的照片/视频瀑布流；点开大图，按下 ♪ 听到那天的歌，点亮一颗星。
2. 他（管理员）今晚想补 3 张上周的照片：/admin → 记忆管理 → 批量上传、补配文和日期、绑定一首歌 → 保存即上线，她刷新可见，全程无需部署。
3. 他想知道她最近有没有来过：记忆管理 tab 的"星星动态"（近 14 天点亮记录）。
4. 未配置素材时，任何登录用户看到温柔的"小屋正在布置中"空状态，而不是报错页。

## 5. 功能需求（FR）

### FR-1 数据模型
- `tb_memory_item`：id、type(photo/video)、mediaUrl、coverUrl（视频封面可空）、title(≤100)、caption(配文≤500)、memoryDate（拍摄/纪念日期）、songId（可空）、冗余 songTitle/songArtist/songCover、status(draft/published，默认 published)、sortOrder、createTime。
- `tb_memory_star`：id、itemId、userId、createTime，唯一键(itemId, userId)。
- 表由 JPA ddl-auto 自动创建；init.sql 仅补注释说明。

### FR-2 展示页 `/memories`（需登录，粉嫩风）
- 顶部：时段问候（早上好/晚上好…）+ "小屋里珍藏着 N 个瞬间 · 你点亮过 M 颗星"。
- **每日瞬间卡**（拍立得风格，白框微倾斜）：服务端确定性挑选 todayPickId（epochDay 对已发布列表取模），当日稳定；无素材时隐藏。
- 瀑布流（CSS columns，无三方库）：全部/照片/视频筛选 + 按月分组；图片经 OSS 缩放参数懒加载（复用 OptimizedImage/ossThumb），视频卡片 preload="metadata" 显示首帧 + 播放角标。
- 灯箱：配文（楷体/衬线排版）、日期、上一张/下一张（键盘 ←/→、ESC 关闭、移动端滑动）、♪ 播放绑定歌曲（歌曲已删则隐藏按钮）、点亮星星。
- 视觉：页级粉嫩 CSS 变量（`--mem-*`）+ `memories-scope` 作用域 class，不动全局主题；漂浮花瓣/爱心粒子（≤30 个，reduced-motion 降级）、stagger 入场动画、拍立得卡片微倾斜。

### FR-3 管理端（/admin 新 tab「记忆管理」，仅管理员）
- 上传对话框：批量选择图片/视频 → 逐个传 OSS（进度条）→ 统一补标题/配文/日期/绑定歌曲（复用 SongSelector）→ 保存。
- 列表：缩略图、配文、日期、绑定歌、状态；操作：编辑/下架/发布/删除（删 DB 行 + 同步删 OSS 对象）。
- 星星动态：近 14 天点亮记录（日期 + 哪张素材），给他"她来过"的轻信号。

### FR-4 上传接口 `/upload/memory`（仅管理员）
- 允许 image/*（≤10MB）与 video/mp4、video/quicktime、video/webm（≤200MB）→ OSS `memory/` 目录。
- application.yml multipart 上调：max-file-size 200MB / max-request-size 210MB。既有接口（头像 2MB/封面 5MB/音频 30MB）各自有独立校验，不受影响。

### FR-5 音乐绑定
- **v1.1 增量（2026-09-12）：歌曲海绑定提前落地**——原 P1 仅本地曲库，但适合做树洞 BGM 的歌（如陪你度过漫长岁月）多在歌曲海。现支持双来源：
  - local（默认）：绑定本地 songId，冗余字段由曲库回填；歌曲删除 → 绑定清空、♪ 隐藏。
  - gequhai：绑定歌曲海 sourceTrackId（新增 songSource/songExternalId 两列）；冗余展示字段由管理端选歌时传入；播放走 `/music/external/stream?source=gequhai&trackId=…` 免登录流式代理（列表/表单带"试听"标识，与曲库供应链 v1 定性一致）。
- 播放统一走既有 player store 点播管道；整屋导出歌单仍为 P2。
- 选歌器（SongSelector）配套升级：新增「歌曲海」搜索 tab（同一搜索框、防抖复用）；顺带修复两个缺陷——嵌套弹窗遮挡（el-dialog 补 append-to-body，编辑素材弹窗内点选歌不再被压住）、选歌回调歌手名丢失（song.artist 字段此前未被读取）。

### FR-6 可见性
- 全部素材对**所有登录用户**可见（用户决策：不用 private 档）。站内页面需登录即可，与站点其他页面一致。
- 下架（draft）素材仅管理员在后台可见，展示页不出现。

## 6. 非功能需求（NFR）

1. **即传即显**：管理端保存后展示页刷新可见，全程无需重启/重新部署（核心诉求）。
2. **移动端优先**（她大概率手机访问）：单列瀑布流、灯箱滑动切图/下滑关闭。
3. 性能：list 接口单表查询 ≤ 200ms；图片走 OSS 缩放参数；视频不自动加载。
4. 隐私与安全：`/memory/admin/**` 与 `/upload/memory` 仅 ADMIN；小屋页面需登录；OSS 当前为公开读 bucket（知道 URL 即可访问），更高私密性需求 P2 换私有 bucket + 签名 URL。
5. 无障碍与体感：动画尊重 prefers-reduced-motion；页面文案由规格 §3.6 约束。

## 7. 验收标准（AC）

- AC-1 未登录 GET /memory/list → 401；非管理员调用 /memory/admin/**、/upload/memory → 403。
- AC-2 管理员上传 1 照片 + 1 视频（含配文/日期/绑定歌）→ 保存后登录 /memories 可见；灯箱可播放绑定歌曲、可点亮/取消星星。
- AC-3 每日瞬间：同一天内多次刷新 todayPick 不变；次日更换。
- AC-4 下架素材在展示页消失，管理端可见；重新发布恢复。
- AC-5 删除绑定过的歌曲后，对应灯箱 ♪ 按钮隐藏，页面无报错。
- AC-6 250MB 视频上传被拒并返回友好提示；200MB 内成功。
- AC-7 管理端"星星动态"展示近 14 天点亮记录。
- AC-8 既有上传接口自身大小校验与四套 E2E 回归全绿。

## 8. 明确不做（P1）

1. 评论/他人点赞/分享（刻意：零社交压力）。
2. 整屋导出歌单（P2；外源歌曲绑定已在 v1.1 提前落地，见 FR-5）。
3. 视频转码/压缩（需 ffmpeg；引导素材 ≤1 分钟 1080p）。
4. 小羊驼 DJ「暖房电台」工具（P2：DJ 可从记忆墙抽一张照片配一段话）。
5. 管理端拖拽排序（P1 按日期/sortOrder；P2 加拖拽）。
6. 信箱板块（P2 候选：他写信、她拆信）。
7. 素材可见范围 private 档（用户决策：全公开给登录用户）。
