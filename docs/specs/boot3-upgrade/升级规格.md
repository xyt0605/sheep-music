# boot3-upgrade：后端升级 Spring Boot 3 + Java 17（为 Spring AI 铺路）

日期：2026-09-05 ｜ 状态：已实施 ｜ 回归基线：api 111 + rec 20 + ws 7 必须全过

## 目标

- Spring Boot 2.4.13 / Java 8 → **Spring Boot 3.5.x / Java 17（temurin-17）**
- 引入 **Spring AI**（BOM + OpenAI starter），密钥缺省为占位符保证可启动，为 agent-v1 做准备

## 破坏性变更清单与对策

| 变更 | 对策 |
|------|------|
| javax.* → jakarta.*（persistence/servlet/validation） | 全量 sed，涉及 ~40 文件 |
| Security 6：WebSecurityConfigurerAdapter 移除 | SecurityConfig 重写为 SecurityFilterChain + lambda DSL，放行规则逐条对齐 |
| jjwt 0.9.1 不可用（依赖已删除的 javax.xml.bind） | 升级 jjwt 0.12.6（api/impl/jackson 三件套）；JwtUtil 重写为 `Keys.hmacShaKeyFor` + `Jwts.SIG.HS512`；secret 不足 64 字节时用 SHA-512 确定性拉伸；**旧 token 全部失效（用户重新登录即可），e2e 每次重新登录不受影响** |
| knife4j 3.0.3（springfox）不兼容 | knife4j-openapi3-jakarta-spring-boot-starter 4.5.0（springdoc 2.x）；注解迁移 @Api→@Tag、@ApiOperation→@Operation、@ApiParam→@Parameter、@ApiModel→@Schema |
| Hibernate 5.4 → 6.x | 编译期大概率无感，运行期行为差异由 E2E 暴露后逐个修复 |
| mysql-connector-java → com.mysql:mysql-connector-j | 改坐标，驱动类名不变 |
| Java 8 → 17 | 代码无 javax.xml.bind/sun.misc 依赖，源码层面无碍；maven-compiler release=17 |
| Docker 基础镜像 JDK8 → 17 | back/music-project/Dockerfile 改 eclipse-temurin:17 |

## 明确不做

- 不升级数据库/前端；不改业务逻辑；JWT 旧 token 平滑迁移（会全量失效，重新登录即可）

## 验收标准

1. `mvn compile` 通过（temurin-17）
2. E2E 三件套 111/20/7 全过（Boot 3 后端 + e2e 隔离库）
3. 应用启动无 Spring AI 相关报错（占位 key 模式）
4. 浏览器烟雾测试：登录/首页/管理后台正常
