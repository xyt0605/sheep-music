# UI v2 · 大厂设计模式改造规格（SDD-Spec）

> 目标：借鉴 Spotify / Apple Music / YouTube Music / 网易云音乐 的成熟设计语言，对 Sheep Music 做一次系统性 UI 升级与功能完善。
> 关联：上一轮「推荐系统 v2」规格（docs/specs/推荐系统v2/）。本轮仅动前端呈现层，不改任何 API 契约。

## 1. 借鉴映射表（大厂模式 → 本站落点）

| 来源 | 设计模式 | 本站落点 | 优先级 |
|------|----------|----------|--------|
| Spotify | 左侧固定侧边栏导航（品牌+分区+激活态） | Layout：桌面端（≥1181px）侧边栏，顶栏退化为工具条 | P0 |
| Spotify | "Good evening" 问候头 | Home：按时间问候（早上好/下午好/晚上好 + 昵称） | P0 |
| Spotify / 网易云 | 横向卡片架（shelf）+ 左右箭头滚动 + 卡片悬浮播放按钮 | Home：热门歌曲 / 新歌速递由轮播改为卡片架 | P0 |
| Spotify | Recently played（最近播放）架 | Home：新增"最近播放"架（复用 /recent 接口） | P0 |
| Spotify / YouTube Music | 底部播放条 + 右侧队列抽屉（当前高亮、点播、移除、清空） | MusicPlayer：播放列表对话框升级为队列抽屉 | P0 |
| Spotify / 网易云 | 细进度条 hover 增粗、音量图标随音量变化、点击静音 | MusicPlayer 细节 | P1 |
| Apple Music | 克制的表面层级（base/raised/elevated）与柔和描边 | theme.css 设计令牌升级 | P0 |
| 网易云 | 歌单/榜单"查看更多"入口保留 | Home 各架标题行保留 | — |

明确不借鉴：Spotify 全暗色强制（本站有双主题体系，保留）；网易红主色（本站品牌为靛紫渐变，保留品牌一致性）。

## 2. 功能需求

- FR-1 主题令牌：新增/细化表面层级令牌（--surface-raised / --surface-elevated / --overlay-panel 等），双主题各自调优；**所有既有变量名保持不变**（全局组件零改动生效）。
- FR-2 侧边栏：≥1181px 显示固定左侧栏（品牌、分区导航、徽标、管理入口），顶栏保留工具控件（主题切换/桌面歌词/用户），隐藏顶部主导航；<1181px 行为与现状一致。
- FR-3 首页卡片架：热门/新歌由 el-carousel 改为横向滚动卡片架，两侧箭头滚动，卡片悬浮显示播放按钮；点击卡片即播放并以该架为播放队列。
- FR-4 最近播放架：登录用户显示"最近播放"（去重，≤12 首），无记录时整架隐藏。
- FR-5 问候头：按当前时间输出问候语 + 昵称。
- FR-6 队列抽屉：播放列表对话框改为右侧抽屉；当前播放行高亮；行点击切歌、行内移除、底部清空。
- FR-7 播放条细节：音量图标随音量分级、点击静音/恢复；进度条 hover 增粗。

## 3. 非功能需求

- NFR-1 不改 API 契约与 store 状态结构（仅消费既有 state/action）。
- NFR-2 移动端（<1181px）现有体验零回归。
- NFR-3 所有新样式走主题令牌，双主题下均可用。
- NFR-4 构建零错误；历史 E2E（111 + 20）全量回归通过。

## 5. Out of Scope

- 不重做 Discover/歌单详情等内页（已在 v2 推荐改造中更新）；不改登录/欢迎页（上一轮刚调过）；不引入新 UI 框架。
